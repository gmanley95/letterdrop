# Product brief

**What:** Letterdrop, a daily physics-meets-Scrabble word game for iPhone and Android.

**Who:** Wordle-style daily players. Short sessions (3–5 minutes), one-handed, shareable result.

**Flow:** Sign in (guest or name, stored on device) → Home (daily, practice, how to play, settings, stats) → Game (aim, drop, build word ×5) → Results (⭐ top-3 score, words, share, next-puzzle countdown).

**Core loop:** Aim ball → watch it collect letters → spell a word → used slots refill from the tray → repeat.

**Success looks like:**
- A typical player forms at least 3 words most days (needed for a full share score).
- Scores vary meaningfully between players and days, so sharing is interesting.
- Each ball type is the best choice in some situations; none dominates.

**Out of scope for v1:** cloud accounts, leaderboards, multiplayer, sound, in-app purchases.
